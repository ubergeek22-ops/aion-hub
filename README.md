# AION Hub

Catalogue des applications de **Roman Schwenk — Schwenk Systems**, utilisé par l'appli Windows **AION Hub**.

- `catalog.json` : la liste des applis (nom, catégorie, description, version, tailles, lien de téléchargement)
- `icons/` : les icônes
- Les installateurs sont publiés dans les **Releases** de ce dépôt, une par appli et par version.
